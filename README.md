# ✨ Features

- 🎯 15 Multiple Choice Questions
- ⏱️ 5-Minute Countdown Timer
- 💰 Interactive Prize Money Ladder
- 🎲 Three Lifelines
  - 50-50
  - Audience Poll
  - Phone a Friend
- 🔊 Text-to-Speech Voice Feedback
- 🎵 Background Music & Winning Sound Effects
- 📈 Score & Accuracy Tracking
- 🏆 Win & Lose Screens
- 🖥️ Full-Screen Graphical User Interface

# 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/krishnavas23/KBC-Kaun-Banega-Crorepati.git
```

### 2️⃣ Navigate to the Project

```bash
cd KBC-Kaun-Banega-Crorepati
```

### 3️⃣ Install Required Libraries

```bash
pip install pygame pyttsx3
```

### 4️⃣ Run the Application

```bash
python "Python Project (KBC)/kbc+time.py"
```

> **Note:** Ensure all image (`.png`) and audio (`.mp3`) files are present in the project folder before running the application.

# 🎮 Gameplay

- Start the quiz and answer **15 multiple-choice questions**.
- Use each lifeline only **once** during the game.
- Beat the **5-minute timer**.
- Climb the prize ladder with every correct answer.
- Reach the final question and win **£1 Million!** 🏆
